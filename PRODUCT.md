# Miguelito WebUI Product Brief

## Product
Miguelito is a foreign-language chat tutor. The WebUI is the default channel for non-power users who should feel they are opening a calm, trustworthy messenger, not an admin panel.

## Primary user
A language learner who wants to have a natural conversation in the target language with minimal setup and no visible bookkeeping. They may be on mobile, distracted, and uncertain about their skill level.

## Core job
Let the user start or continue a conversation quickly, switch language if needed, and read/write messages comfortably. Spaced repetition, error tracking, and vocabulary scoring should happen in the background.

## UX priorities
1. Chat first: message history and composer dominate the screen.
2. Mobile-first: usable with one hand, safe-area aware, no desktop-only layout assumptions.
3. Low cognitive load: only language selector and chat are visible by default.
4. Continuity: full web history is visible; old messages feel preserved.
5. Trust: warm, quiet, polished, native-feeling surfaces.

## Visual register
Warm light, tactile, almost iOS-like: off-white canvas, soft shadows, restrained sepia accents, compact header, readable message bubbles.

## Voice
Gentle, direct, quiet. Avoid hype. Avoid dashboard language on the main chat screen.

## Anti-references
- Purple/blue AI gradients.
- Glassmorphism as decoration rather than functional depth.
- Neon glows, cyber aesthetics, generic SaaS hero styling.
- Dashboard clutter, charts, progress widgets on the primary chat screen.
- Over-animated chat bubbles or novelty motion.
- Monospace-heavy “AI tool” look.
